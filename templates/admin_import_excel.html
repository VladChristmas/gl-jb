Как это работает

  1. Создайте маппинг для каждого типа файла (Заказы / Жалобы)
  2. Укажите колонки:
    • ID обращения — общая колонка для связи (обязательна)
    • ФИО — только для заказов, для поиска пользователя
    • Номер заказа — только для заказов
    • Дополнительные поля — любые колонки из файла, которые нужно сохранить
  3. Сначала загрузите файл заказов — создадутся заказы с external_id
  4. Потом загрузите файл жалоб — они привяжутся к заказам по external_id

Поля для жалоб (type=complaints)

В дополнительных полях укажите соответствие для сохранения в заказ:

  • complaint_text → текст жалобы
  • complaint_status → статус жалобы
  • complaint_date → дата жалобы (ISO формат)
