Как считается балл и что входит в период

Формула: балл = 100 − (процент заказов с жалобами × K), ограниченный диапазоном 1–100. K = {{ rating.penalty_k }} — настраивается (RATING_PENALTY_PER_PERCENT). Округление — только при отображении. Пример: 4 заказа, 1 с жалобой → 25% → балл 75.0; 0% жалоб → 100; 100% жалоб → 0 → нижняя граница 1.

Процент заказов с жалобами = заказы с жалобами ÷ заказы периода × 100. Если заказов за период нет — показывается «—», а не 0%. Заказы считаются по одной строке на заказ: жалоба учитывается один раз, даже если в ней несколько позиций.

Период — календарная неделя с понедельника, в UTC: [Пн 00:00, Пн+7 00:00). Заказы учитываются по {{ 'дате создания' if rating.date_source == 'created_at' else 'дате доставки' }}; заказы без распознанной даты в период не входят и показаны отдельной цифрой «Без даты». Жалобы привязываются к заказу, а не к дате обращения (дата обращения — отдельный показатель в KPI).

Минимальная выборка — {{ rating.min_orders }} заказов за неделю (RATING_MIN_ORDERS): меньше — балла нет, курьер попадает в блок «Недостаточно данных».

Место — по баллу (больше — лучше), при равенстве: меньше процент жалоб, затем больше заказов. Полностью равные показатели делят одно место. Предыдущая неделя считается той же формулой (понедельник − 7 дней).
