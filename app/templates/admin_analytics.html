Методология и определения

Источники данных: таблица Complaint (каждая строка — одна причина жалобы) + зеркало Order.complaint_text (разделяется по «; » для легаси-данных).

Жалоба vs Заказ с жалобой: одна жалоба = одна строка Complaint; один заказ может иметь несколько жалоб. Метрика «Заказов с жалобами» считает уникальные заказы.

Доля жалоб (%): жалобы ÷ заказы × 100 за тот же день/период. Позволяет отделить рост жалоб от роста объёма.

Причины: текст жалобы разбивается по разделителю «; ». Известные темы (фото-требуемые) выделяются отдельно; остальные группируются как есть.

Фильтры: применяются ко всем агрегациям одновременно. Период — по дате создания жалобы (Complaint.created_at), а не заказа.

Ограничения: корреляция ≠ причинность. Аналитика показывает совпадения; выводы делает руководитель.
